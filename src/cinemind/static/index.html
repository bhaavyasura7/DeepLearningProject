How it works

Everything runs on this computer: a local AI model (via Ollama) and real movie data (MovieLens 32M ratings + TMDB descriptions).

Youa typed request, or a viewer's rating history
→
1 · UnderstandAI turns it into likes, dislikes, rules
→
2 · Find candidates Text similarity: movies whose description reads like your profile Movie graph: walk from movies you liked through shared director / actors / genres
→
3 · JudgeAI scores each of ≤50 candidates (10 per call)
→
4 · SummariseAI writes a short brief
→
5 · Rank + checksAI picks 5; code drops anything not found, copies exact quotes

Why a graph?

A brand-new film has no ratings yet, so rating-based systems can't recommend it. But it already has a director and cast. If you loved Inception, the graph reaches Oppenheimer through "Director: Christopher Nolan" on day one.

Why can you trust the answers?

Three checks run in code, not in the AI: every pick must be a real movie from the candidates; movies already watched are removed; the quote is copied word-for-word from the description.

What if the AI misbehaves?

Bad output is retried once. If it fails again, a simple rule takes over and the step is marked backup rule used. It is never hidden.

Saved runs

Each example was run once with the real AI and saved. "Saved run" replays it instantly, so the demo works without the model or internet.
